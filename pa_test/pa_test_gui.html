🔢 PA Test · Control Panel

Pressure-advance research via StallGuard · measures how fast melt pressure builds in your hotend.

1Before you start

    2What this does

    Prototype. This plugin currently ships one command — a feasibility probe. It does not calculate a pressure-advance value yet; it measures whether your hardware's StallGuard signal is clean enough to build the full PA search on.

    Pressure advance compensates the melt pressure that builds up in the nozzle. That pressure loads the extruder motor, and motor load is what StallGuard measures. The probe steps the extrusion rate between a low and a high flow (pure E-moves, no XY motion, PA not involved) and records the load response at 50 Hz.

    1. Heat the hotend to printing temperature and load filament.
    2. Position the nozzle over the purge bucket / off the bed — this extrudes several centimetres of filament.
    3. Run the probe and read the verdict line in the console.

    3Settings

    The bigger the gap between low and high flow, the stronger the signal. Pick a high flow you know your hotend handles — if you ran the TMC Flow Test, use a value clearly below its result.

    4Run it

    Moonraker URL: (sending needs your browser origin in Moonraker's cors_domains — otherwise use Copy & paste into the console)

    📊 Reading the result

    The console prints a summary; the full time series lands as a CSV in the output folder.

    SG step — how far the load signal moves between low and high flow. Bigger is better.
    SNR — the step divided by the sample-to-sample noise. ≥ 5 means the signal carries enough information to build the full PA search on. Below that, widen the flow gap and retry.
    Rise time — how long the pressure needs to settle after a flow jump. This is the physical quantity pressure advance compensates: a longer rise time means more PA.
    Overshoot — how far the load shoots past the new steady level. Near zero is expected on a healthy extruder.

    ❓ Help

    StallGuard reads 0 / the probe refuses to run

    Same driver requirements as the flow test: SG2 drivers (TMC5160/2130/2240) need SpreadCycle, the TMC2209 needs StealthChop, and both need coolstep_threshold plus a sensible driver_SGT. Run TMC_FLOW_STATUS from the flow-test plugin — it names the exact problem.

    Nothing extrudes / hotend too cold

    The probe refuses to run below the configured minimum temperature. Heat with M109 S250 (your printing temperature) first.

    What happens with the result?

    Send the CSV to the plugin author — the measured rise time and SNR decide how the full PA search (per-flow bisection and an adaptive-PA table for OrcaSlicer) will score candidates.
