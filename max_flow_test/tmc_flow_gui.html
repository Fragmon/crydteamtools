    ❓ Help

    The hotend must be hot

    The test extrudes real filament. Heat the hotend to your printing temperature (M109 S250) and load filament first — the plugin refuses to run below its minimum temperature. Extrude over the purge bucket or with the nozzle away from the bed.

    How does it detect the limit?

    It raises the flow step by step and watches the TMC StallGuard load signal. When the extruder gear starts slipping or grinding, the signal changes character (variance spikes, brief load collapses or unload peaks) — that's the limit. Then it bisects to ±1 mm³/s and verifies.

    StallGuard reads 0 / nothing is detected

    StallGuard needs the right driver setup: SG2 drivers (TMC5160/2130/2240) need SpreadCycle (no stealthchop_threshold), the TMC2209 needs StealthChop. All need coolstep_threshold set and a sensible driver_SGT. Run the status check — it names the exact problem. For SGT use the SGT calibration and then SAVE_CONFIG.

    Starting at a high flow

    Safe: two fixed low reference steps run first and give the detection a clean baseline. Set REF_FLOW=0 only if you know why.

    Where are my results?

    Every run writes a CSV and an interactive HTML report into the Flowtest folder inside your config directory. Open the HTML in a browser — it shows the curve, the decision trail and the recommended slicer value.
